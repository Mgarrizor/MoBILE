# Logos shown in the app

- `ictp.png` (or `.svg`, `.jpg`): top right of the app.
- `funders/`: one image per funding entity, shown at the bottom in alphabetical order of file name.

Until a file is here, the app shows an empty placeholder. Check that you may use a logo before adding it.

# Documentation

- `docs/`: the built Sphinx documentation, shown in the Docs tab. Copy it here when preparing a release
  (`sphinx-build -b html ReadTheDocs/docs/source python/mobile/assets/docs`); until then the tab shows a placeholder.
